- [开发说明](DEVELOPMENT.md)：源码运行、目录结构、ASR 接口和测试。
- [浏览器扩展](BROWSER_EXTENSION.md)：安装、网站授权和扩展构建。
- [戒指固件更新](FIRMWARE.md)：用户升级流程和开发者替换随包固件。
- [仓库内容与本地数据](REPOSITORY_CONTENTS.md)：哪些文件允许提交以及如何启用检查。

项目简介和下载入口见 [仓库首页](../README.md)。
