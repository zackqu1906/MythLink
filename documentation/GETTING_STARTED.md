# 安装与使用

## 安装

从 [GitHub Releases](https://github.com/zackqu1906/MythLink/releases) 下载对应系统的安装包：Windows x64 使用 `.exe`，Apple Silicon macOS 使用 `.dmg`。仓库的源码 ZIP 需要自行[构建](BUILDING.md)。

macOS 将 Mythlink 拖到 Applications。首次启动按功能提示授予蓝牙、辅助功能等权限；使用电脑麦克风时允许麦克风。需要屏幕上下文时按提示授予屏幕录制权限。本地 ASR 和文本模型在首次使用时按需下载。

## 连接与输入

1. 在主界面扫描并连接自己的戒指，确认连接状态。
2. 在设置中选择语音输入源、识别后端和文本模型；云端服务使用自己的 API Key。
3. macOS 行内输入先在「设置 → 系统与权限」安装或更新输入法，在目标文本框内选中 Mythlink 输入源。
4. 使用界面或配置的手势开始、结束听写。需要中文拼音时切回系统输入法。

语音编辑针对当前可编辑文本；屏幕上下文用于辅助理解。可以在设置中配置语音编辑模型和提示词。撤销和继续编辑依赖当前输入目标与输入法状态，切换目标后不要沿用上一输入框的操作。

macOS 的「语音输入后切回原输入法」是可选项。输入法更新前先结束进行中的语音或笔画输入。Windows 可使用右 Alt 按住说话；具体入口以系统和设置为准。

## 触摸、笔画与手势

在平面触控设置中选择鼠标或笔画输入，配置点击、方向手势和快捷键。笔画模式提供候选字、退笔和清空；连笔适配保留单笔解释并提供连笔备选。可按应用和场景设置不同操作。

macOS 笔画模式中，双指左滑抬手退一笔，没有笔画时退格。继续向左外拉，有笔画时提示「清空」，没有笔画时提示「删除前文」，抬手删除光标前的全部文字并保留后文；有选区时删到选区末尾。拉回中心再抬手取消。单指左右往返三段只清空笔画。双指双击退出笔画模式。

触摸板启动时若戒指暂忙，应用最多等待重试两次；这个状态不一定由充电引起。运行中若戒指报告触控计算异常，应用会在确认旧数据流停止后取消未完成的手势，并尝试恢复一次。若仍然失败，请重新开启触摸板或重连戒指；反复出现时可导出诊断记录排查固件。

应用操作、输入操作与当前焦点相关；在实际目标应用中验证自己的手势配置。浏览器媒体控制需要单独安装并授权[浏览器扩展](BROWSER_EXTENSION.md)。

## Agent 工作区

macOS 可在「设置 → Agent」连接本机可用的 Codex，按页面提示完成登录与工具检查。连接后从设置或托盘唤起工作区，输入任务、回答追问或取消任务。这里的 Agent 是产品功能；开发项目时产生的 Agent 工作日志不会随应用发布。

## 历史与导出

语音历史提供详情、筛选和导出；手势历史可查看识别与执行结果。故障排查页面可筛选并导出诊断记录。导出的内容可能包含自己的输入文本，分享前检查所选范围。

已安装应用的数据按操作系统用户隔离：

- macOS：`~/Library/Application Support/ProxiMic Voice`
- Windows：`%LOCALAPPDATA%\ProxiMic Voice`
- macOS 模型缓存：`~/Library/Caches/ProxiMic Voice`

应用不会附带开发者的录音、聊天历史或诊断数据。固件升级步骤见[戒指固件更新](FIRMWARE.md)。
