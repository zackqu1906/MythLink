# 方法依据与决策记录

日期：2026-11-02。任务：单枚手指戒指，抬到嘴边准备说话。现有训练仍评价 IMU 动作检测；v2 采集已增加音频与独立标签，最新采集方案见 [multimodal.md](multimodal.md)。

## 参考论文及可借鉴范围

1. Buddi et al., **Efficient Multimodal Neural Networks for Trigger-less Voice Assistants**, Interspeech 2023，§3.1–3.4、§4。
   - [官方页面](https://www.isca-archive.org/interspeech_2023/buddi23_interspeech.html)；[全文](https://www.isca-archive.org/interspeech_2023/buddi23_interspeech.pdf)。
   - 该工作在手表上先训练动作/语音检测器，再融合；动作分 raising、raised、dropping、dropped，10 Hz 输出。采集包含多种日常场景，用视频辅助动作标注，参与者不跨 train/val/test。
   - 本实验借鉴阶段标注、连续负例、10 Hz 决策和隔离划分。它使用手表加速度与音频，我们使用手指戒指六轴；本文架构、窗口和性能不能直接照搬，也不复现其完整多模态系统。
2. Li et al., **Enabling Voice-Accompanying Hand-to-Face Gesture Recognition with Cross-Device Sensing**, CHI 2023。
   - [作者预印本](https://arxiv.org/abs/2303.10441)。
   - 研究手到脸的语音伴随手势，组合声音、超声与 IMU 等跨设备信号。对本实验的启发是系统性收集接近脸部的易混动作，并把“动作识别”和“语音意图”分开。
   - 该论文的多模态识别结果不构成本戒指仅用 IMU 就能识别说话意图的证据。
3. He et al., **WritingRing**, CHI 2025，§5.2；**TraceRing**, CHI 2026，§5.1.1。
   - [WritingRing 原文](https://pi.cs.tsinghua.edu.cn/wp-content/uploads/2025/06/3706598.3714066.pdf)；[TraceRing 原文](https://pi.cs.tsinghua.edu.cn/wp-content/uploads/2026/04/3772318.3790463.pdf)。
   - 前者使用 Madgwick，后者使用 VQF 估计姿态，移除局部坐标下的重力分量，再做轨迹相关学习。
   - 当前目标包含姿态辨别，首版保留含重力加速度。去重力可能丢掉有用的倾角线索，不能因为手写任务这样做就照搬。以后可增加 raw 与 raw+gravity/linear 的严格消融；先保证相同数据划分和因果滤波。
4. Dehghani et al., **A Quantitative Comparison of Overlapping and Non-Overlapping Sliding Windows for Human Activity Recognition Using Inertial Sensors**, Sensors 2019。
   - [论文全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6891351/)。
   - 借鉴其对窗口重叠、受试者相关性和评估方法的讨论。连续窗口并非独立样本；本文先按参与者/佩戴批次分组，再切窗，事件指标也不把大量重叠窗口当作大量独立动作。

## 从原始包到训练样本

1. **协议来源冻结**：两个 SDK 协议文件与用户提供 ZIP 一致。仅引用协议代码和 API 资料，不执行附件中的固件升级指引。
2. **采集保持可追溯**：原始 BLE RX/TX、int16、SI 单位、设备/主机时间、版本和 SHA-256 一起保存。没有去重力、自动校零、单位外的归一化或世界坐标旋转。
3. **时间质量**：包末时间来自硬件，包内由请求频率回填；处理 uint16 序号与 uint32 时钟回绕。设备重启、重叠时间或错误编码中止录制；丢包产生新段。模型窗口不跨段或 >15 ms 缺口。
4. **真值独立于提示**：采集引导只是草稿。必须基于实际观察 / 录像复核，边界不明的数据排除。人工按键、提示和 BLE 到达均有延迟，不能宣称硬件同步。
5. **目标与反例**：初版正例是有意准备对戒指说话的完整抬手；v2 将相同口旁抬手运动与意图分开标注（禁止直接混用两个标签版本）；喝水、进食、摸脸等即使到嘴边仍是负例。真实 IMU 中可能存在无法区分的轨迹，应报告失败类别，而不是重新定义负例消除错误。
6. **划分先于切窗**：个人模型按独立批次隔离；多人模型按用户隔离。不能用随机窗口划分声称跨天或跨用户泛化。
7. **因果窗口**：仅使用截止当前时刻的历史样本；插值只在连续段内，右端最多保持一个已知过去采样，不使用未来值。1 秒/200 Hz/100 ms 步长是待验证的初始超参数，每窗为 6×200 个值；与语音分支统一为 1 秒历史。此值是本项目的实验选择，不是苹果论文参数的复现。
8. **训练统计量**：均值、标准差只来自训练窗口；验证选早停与事件阈值；测试只在模型确定后使用。保存代码哈希、数据来源、模型哈希、随机种子及依赖版本。

## 首版模型与事件定义

统计基线：每轴均值、标准差、最小、最大、末值、首尾四分之一窗口均值差，共 36 特征，线性四分类。CNN：三层左侧补零的因果一维卷积、8 段池化及四分类头。两者使用相同窗口、标准化和决策规则。

模型输出四类分数。第一次 near_mouth 分数连续 3 帧过阈值产生候选。抬手开始至嘴边保持结束之间允许匹配到同一次动作；报告相对开始抬手及实际到嘴边的延迟，提前触发不伪装成正延迟。目标内额外触发计重复事件。放下或背景期间的触发计误触。

参考姿态标签只能表示“与嘴边说话姿势一致”，不提供绝对手部位置或嘴部距离。v2 采集已加入戒指麦克风和独立语音/意图复核；目前没有真实语音标注训练集，也没有训练音频融合模型。

## 质量与验收顺序

| 阶段 | 要回答的问题 | 通过后再进行 |
| --- | --- | --- |
| A 协议检查 | 命令、单位、轴顺序、回绕与异常拒绝是否正确？ | 实物静止/六朝向检查 |
| B 小批次采集 | 实际信号、丢包、佩戴记录、动作边界是否可信？ | 独立批次正式采集 |
| C 数据整理 | 标注复核、来源哈希、批次/用户隔离是否成立？ | 训练两个基线 |
| D 验证 | 同样数据下 CNN 是否优于简单基线？误触来自哪些动作？ | 冻结模型和阈值 |
| E 留出测试 | 新批次事件召回、误触/小时、延迟是否可接受？ | 真实连续观测 |
| F 连续观测 | 日常任务中的误触、固件/佩戴变化是否暴露失效？ | 决定是否加入语音等辅助信号 |

软件自检可覆盖 A 和 C–E 的流程正确性，不能替代 B 或 F。合成数据明确标记并默认拒绝进入真实数据构建，合成训练模型禁止真实在线模式。

## 指标解释边界

- 分母包括实际可评估的目标事件；因缺口/预热排除的事件单独报告，不能悄悄消失。
- 误触/小时按有效负例时间计算；缺口与未知标注不贡献曝光。目标内重复触发单独计数。
- Wilson 召回区间与 Poisson 误触上限是描述性参考。同一用户重复动作有相关性，并不满足完全独立假设。正式多人试验宜做按用户/批次的聚类 bootstrap。
- 设备时间上的检测延迟不含 BLE 传输/主机排队；单次 CPU 前向耗时也不是完整产品延迟。
- 少量个人数据只能说明该人、该佩戴条件的可行性，不支持新用户泛化或长期低误触结论。

所有性能阈值、窗口和采样容差均为首版可审查设计选择，不是从论文抄出的已验证最佳值。
