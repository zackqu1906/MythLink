Mythlink · macOS

融合语音输入、鼠标控制、手势识别与场景联动的戒指交互平台。

支持 Apple Silicon（M 系列）Mac，macOS 15 或更新系统。
内置主程序、语音输入法和安装工具，无需 Python、Xcode 或终端。

首次安装
1. 将 Mythlink.app 拖到 Applications（应用程序），再从应用程序打开。
2. 主界面点击“输入法设置”→“安装／更新输入法”。
   组件会安装到当前用户的 Library/Input Methods，安装器不会切换输入法。
3. 首次打开主窗口时，会依次向 macOS 申请蓝牙、麦克风、辅助功能和屏幕录制权限。
   已授权的项目不会再次弹窗；之前已拒绝的项目可能需要到系统设置中手动开启。
   如果系统未继续显示下一项，可在“设置→系统与权限”点击“请求权限／继续授权”。
   授权后会自动检测；系统要求重新打开应用时，请按系统提示操作。
   麦克风用于电脑音频，戒指收音不需要电脑麦克风；屏幕录制用于窗口总览预览。
4. 连接戒指，配置语音识别及编辑模型，开启识别。
   云服务需要你自己的服务配置；本地模型在首次使用时下载。
5. 点入 Codex 或微信输入框，在菜单栏手动选择 Mythlink。
   若没有该输入源，打开系统设置→键盘→文字输入→编辑，在简体中文中添加。
   系统输入源列表未刷新时，可注销并重新登录后再添加。

Agent 与常用操作推荐
- 在“设置 → Agent → 连接 Codex”安装并连接 Codex；使用自己的账号登录，成功后显示绿色“已连接”。
- 电脑操作需在 Codex/ChatGPT 中启用 Computer Use，并完成该应用要求的权限。
- 在“设置 → Agent → 下一步推荐”开启推荐，使用 Computer History 的近期活动记忆。
  活动资料可用后会在后台更新；选择建议可交给 Agent，或返回对应的已有任务。
- 无需下载 BGE-M3，也无需先提取 Workflow。旧提取、归组和推荐流程不再随包提供，
  已保存的任务与 Workflow 记录仍可查看。

使用
- 浏览器视频与音频：设置 → 浏览器媒体控制，选择要连接的 Chrome 或 Safari。
  新浏览器会自动添加视频、音乐默认场景；已有手势设置不会被覆盖。
  Chrome 测试版：点击“安装 Chrome 扩展”会复制目录并打开安装页。开启开发者模式，
  点击“加载已解压的扩展程序”，按 Cmd+Shift+G 粘贴目录并选择。不需要另行下载扩展 ZIP。
  Safari：扩展随主程序安装，点击“启用 Safari 扩展”直接打开设置，勾选助手并允许网站访问。
  未公证测试包还需 Safari 开发设置允许未签名扩展；Safari 重启后系统会复位此开发许可。
  授权后刷新页面，首次点击播放器播放一次。识别成功显示进入视频或音乐模式的短提示，
  戒指执行“场景与手势”中该浏览器、该场景的设置。暂停仍保留场景；输入框内优先输入。
- tap 开始／结束听写；说话时文字有下划线。
- 下划线期间触发“转换为编辑”手势，结束本句并按指令编辑。
- 撤销编辑先还原为听写，再次撤销移除指令句。
- 设置中开启“多次撤销”可继续回退之前的听写／编辑，默认关闭。
- 需要拼音时手动切回。主程序需要保持运行。

更新
先结束当前语音或笔画输入，退出旧主程序，替换应用程序里的 app。
打开新主程序，在“设置”→“系统与权限”点击“更新输入法”，更新系统中单独安装的组件。
即使当前使用 Mythlink 也能直接更新：程序会临时切到已启用的系统键盘，安装结束后恢复 Mythlink。
若期间切换了应用或输入法，则保留当前选择。首次安装时不会自动切换输入法。
输入法更新与主程序辅助功能权限独立。权限未生效时，主界面会显示警告。
正式证书签名的版本在保持相同开发者、应用标识和组件身份时，正常覆盖更新通常会保留已有权限。
从临时签名版本首次切换到正式签名版本，可能需要重新授权一次；距离解锁的钥匙串访问也可能需要重新确认。
屏幕录制等权限仍受 macOS 自身的确认规则影响，不能保证系统永远不再提示。
重新授权后无需例行重启，程序会在后台自动检测，生效后请重新触发刚才未完成的操作。
若持续未生效，核对“输入法设置”中的当前运行位置，必要时删除旧权限条目并添加新版 App。
程序会自动重建内部按键通道以读取新授权，主界面和设备连接保持运行。
不要同时从 DMG、下载目录和“应用程序”运行多个同名副本；可复制权限诊断协助排查。

正式构建使用 MythLink 的 Developer ID Application 证书；Apple 公证需要单独完成。
未公证或显式构建的临时签名测试包在其他 Mac 下载后可能被 macOS 拦截；确认来源后，可在系统设置→隐私与安全性中按系统提供的方式允许打开。
输入法组件若另有拦截提示，也需要按系统提示允许。无需关闭系统安全功能。
