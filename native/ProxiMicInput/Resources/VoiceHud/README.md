# 语音输入法浮窗素材

2026-10-28：手势图标与当前 v5 手势控制页统一。`gesture-*.svg` 逐字节复用 `src/proximic_ring/ui/assets/figma/redesign-567-33097-*.svg`，这组手势图标在 v5、v6 中相同；来源为 Figma 文件 `lTJ3fi0mMULAjIsnF8ybwH`。`manifest.json` 记录每个图标的源文件、图层、原始尺寸和 SHA-256。Qt 教学及语音预览中的副本也与原生资源一致。

操作提示采用“手势图标＋功能文字”：输入中显示“取消”“修改”“润色”，定稿后按原有状态显示“撤销”“润色”。双次手势使用同一原图并标注数字 2。多个备选手势仍保持紧凑显示，完整绑定及操作含义通过悬停提示和辅助功能标签提供。`function-*.svg` 为历史素材，输入法浮窗不再绘制功能图标。

状态波形、加载圆弧、三点加载、完成与错误标记保留原有 Figma 资源。加载圆弧由独立 Core Animation 图层持续旋转，减少动态效果时使用透明度变化。状态内容沿用 100 ms 的可中断淡入。

默认 80% 时浮窗高 32 pt，设置可调整至 140%。状态区宽度稳定，操作区只为当前可用按钮分配空间；文字最小 11 pt。浮窗保留非激活窗口、原有光标锚点、五秒隐藏及发送后的隐藏时机。取消／编辑鼠标回调保持不变，润色仍只由主程序处理；不新增 Tap／确认提示或新的点击行为。

主程序通过原有 `configure_hud` 消息同步当前绑定和缩放，重连后重新发布。样式更新不更改快捷键、撤销历史、输入目标或语音会话。

`scripts/build-input-method.sh` 将整个目录复制到输入法的 `Contents/Resources/VoiceHud`。源码启动 Qt 主程序不会替换系统已安装的输入法；需要通过现有“安装／更新输入法”流程更新原生组件后，已安装的输入法才会显示新样式。
