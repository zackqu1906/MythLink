# 语音输入法浮窗素材

来源：MythLink Figma，2026-10-08。按用户最终指定的原件实现：

- [左滑＋取消／撤销](https://www.figma.com/design/KHu0n7WydXkMMHC8pp2TFo/MythLink?node-id=489-1732)：灰色左箭头、蓝色叉号。
- [右滑＋转换为编辑](https://www.figma.com/design/KHu0n7WydXkMMHC8pp2TFo/MythLink?node-id=503-1776)：灰色右箭头、蓝色井号。
- 听写波形：`503:1789`；加载圆弧：`503:1815`；三点加载：`503:1816`。白底、描边、圆角和图标卡片来自 `503:1784` / `503:1802`；保留原有状态文字与错误原因。
- `manifest.json` 记录每个原版 SVG 的图层、原始尺寸和 SHA-256。文件未改色、未重绘；原生 NSImage 直接读取 SVG。
- `gesture-*.svg` 只表示物理手势，`function-*.svg` 只表示功能。提示不绘制功能文字，两类图标在视图中独立组合。主程序通过独立的 `configure_hud` 消息同步配置，重连时重新发布；不会重新配置快捷键、撤销历史或语音会话。
- 主界面「语音输入」直接展示主手势、备用手势和实时图标预览。Qt 资源位于 `src/proximic_ring/ui/assets/figma/voice-hud`，与原生资源逐字节对照；设置仍调用现有 `setGestureBinding` 并使用原有冲突校验。
- `processing-dots.svg` 是 Figma 的三点加载图案，运行中只对整张图片做透明度动画；不替换为系统转圈图标。
- `processing-spinner.svg` 原版圆弧由独立 Core Animation 图层绕中心持续旋转（0.8 秒／圈），不旋转文字或整个浮窗；连续状态更新不重启动画，结束／隐藏立即停止。系统减少动态效果时改为透明度变化。
- 浮窗默认 80%（48 pt 高），「设置 → 界面显示 → 输入法浮窗大小」可调 80%～140%，沿独立 `configure_hud.scale_percent` 同步和持久化；文字最小 11 pt。状态区宽度稳定，操作区按实际可见按钮数量自适应；隐藏的按钮不占位，零按钮时移除整个操作区及间隔。左侧锚点与高度不随按钮数量变化，右侧只保留正常内边距。
- 状态内容使用 100 ms 的可中断交叉淡入；仍复用同一非激活窗口，状态／按钮立即更新。无动画完成回调、最短展示时间或延迟隐藏；原有五秒关闭与光标锚点逻辑保留。
- 听写波形直接加载 Figma SVG，是原有听写状态的指示，不代表实时音量。
- `scripts/build-input-method.sh` 将整个目录复制到输入法的 `Contents/Resources/VoiceHud`，正常主程序构建会包含该输入法组件。
- 源码启动 Qt 主程序不会替换系统已安装的原生输入法。修改浮窗后还需通过现有「安装／更新输入法」流程更新 `~/Library/Input Methods/ProxiMicInput.app`；安装器只在本输入法未选中时替换组件。

界面沿用现有会话状态、取消／编辑鼠标回调、定位与隐藏时机。只保留原有两种操作，不新增 Tap／确认提示；当前阶段不可用的操作按原逻辑隐藏，未绑定手势不影响原有鼠标按钮。文字说明仅用于工具提示和辅助功能标签。
