# 折笔与往返清空专项采集

双击 `scripts/collect-clear-fold.cmd`，建立**新记录**使用扩展计划v2。先断开完整测试窗口或主程序的戒指连接，再连接此采集窗口。默认探索采集2轮共168笔；可以先设1轮采84笔，也可分次续采。独立验证默认2轮168笔。

每轮84笔随机交错：

- 横折弯钩与横撇弯钩各10个变体：自然、小幅、大幅、快慢、浅／深下降（横撇弯钩为浅／陡撇段）、小末钩与段间停顿。
- 其他23种折笔各2个变体：自然与小幅。覆盖横折折、横折折折、横折折折钩、竖折折、竖折折钩、横折折撇、横斜钩、横折提、竖提、撇折、撇点、各种弯钩等，按现有25种折笔目录完整采集。
- 10个真正清空对照：左右起步、3／4段、自然／小幅及换向停顿；4个仅两段往返；横、竖、撇和浅撇4个普通对照。

重点保留横向反转次数、下降幅度、末钩幅度及段间时间。相邻往返换向很像清空的折笔不要刻意“修正”得更规整。

预热达到200/200后，按 **1／Enter** 开始，完整动作抬手后按1保存并开始下一笔，或空格只保存；动作做错才按 **2** 重采。屏幕显示的是当前模型预测；真实完成提示就保存，预测为清空的横折弯钩、横撇弯钩及其他折笔尤其要保留。此窗口不删除文字，不执行清空。

数据存入本项目 `data/recordings/clear-fold`，包含原始尺寸轨迹、逐帧SDK位移、接触边界、预测动作、横向段数与占比、重采和中断，支持自动保存及续采。已输入正文或目标字不参与预测。

旧v1记录仍按原36笔／轮计划续采，原标签、已保存样本和草稿保留；不会将旧计划自动改成84笔。新增折笔需建立v2新记录。

当前预测已加入竖直结构与本地笔画模型复核，见 [复核说明](CLEAR_REVIEW.md)。探索记录用于选规则，另一个独立会话用于验证；不把同一批样本的拟合命中率当成实际准确率。新保存样本记录当时的复核政策；已有预测及原标签不重写。

更新：写之前会显示当前目标笔形的具体字例，特别区分斜钩（戈）、弯钩（家）、卧钩（心）；只写提示的那一笔。字例在显示时追加，旧任务标签与说明不变，仍可续采旧记录。本次168笔回放和模糊识别范围见 [汇总](STROKE_FUZZY_REVIEW.md)。
