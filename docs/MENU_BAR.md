# macOS 菜单栏连接状态和电量

macOS 使用 `ui/menu_bar.py` 的原生 NSStatusItem，44 × 22 点的紧凑图标：

- 左侧保留应用图标；右侧上层是连接状态点（蓝色已连接，红色断开）。
- 右侧下层为主界面同款电池轮廓及填充，≤15% 红色、≤35% 黄色，其余绿色。
- 断开或电量未知时电池灰色，显示短横线，不保留旧电量；充电显示电池内闪电。
- 菜单栏不显示文字；准确百分比和连接状态保留在悬停与辅助功能描述中。
- 设置首页的“菜单栏图标”开关控制附加信息，默认开启。关闭后宽度缩回仅应用图标；
  开关立即生效并通过 `ui/menuBarStatusInfo` 保存，下次启动沿用选择。

主入口订阅连接与电量变化，按事件刷新；相同状态不会重复绘制。菜单继续使用原有
QAction 的回调及启用规则，保留显示主窗口、连接／断开、开启／暂停识别和退出。
关闭主窗口仍退出主程序。退出时只移除自己持有的菜单栏项目。

原生后端初始化失败时回退现有 Qt 图标菜单；其他平台继续使用 QSystemTrayIcon。
AppKit/Foundation 使用项目已有的 PyObjC 环境，不访问辅助功能、模型或用户原文。

验证：10 项显示策略／回调／释放测试；真实 macOS 独立原生检查覆盖两层图标、无文字及悬停信息、
菜单禁用和标题刷新、回调以及连续创建销毁两次。独立检查不连接设备、不向其他应用发按键。
源码主程序重新启动后生效；本次未更新已安装 App 或 DMG。
