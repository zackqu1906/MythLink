# 清空前的笔画复核 v1

2026-10-12 接入完整测试窗口及折笔专项采集窗口。重新打开 `scripts/test-complete-stroke-input.cmd` 使用更新。

## 执行顺序

抬手后先识别七向选字／标点，随后使用原几何规则判断清空候选。真正准备清空时，增加本地竖直结构复核：取等弧长64点，检查中间10%–85%路径是否存在有幅度且连贯的下降；起笔和末钩分开处理。不用目标笔画、目标字或提示标签参与判断。

若没有明显下降结构，沿用清空判断，不加载笔画模型。若有，则用当前固定32点DTW与个人模板识别整笔；有折类支持就保留为笔画。结果与距离复用到后续笔画输入，避免同一笔重复识别。窗口会显示“已按笔画保留”。

若竖直结构明显但模型判断弱或不一致，仍按笔画解释并提示识别需确认。模型失败或完全无法识别时，不清空已有笔序，提示重写本笔；完整轨迹与复核原因写入日志。此复核使用已有本地笔画模型，没有接入云端大模型。

## 固定参数与边界

| 项目 | v1 参数 |
|---|---:|
| 竖直跨度／横向跨度 | 至少0.50 |
| 中间路径的净下降／整笔原始路径长度 | 至少0.15 |
| 中间路径向下路程／竖直总路程 | 至少0.75 |
| DTW折类距离 | 不超过0.08 |
| 折类距离相对首选的差距 | 不超过0.01 |

前三项同时满足才复核模型。末钩方向用于记录，未作为必需条件，保留横折折撇等没有末钩的折笔。模型明确与不确定结果都会保护满足竖直结构的轨迹，区别体现在提示与日志；这些距离不是概率。

原清空候选条件、七向菜单、标点和候选排序保留。2026-10-13 删除已改为一次接触内左→右两段；单独左滑不再删除，旧语境辅助移除，详见 [完整测试说明](COMPLETE_STROKE_TEST.md)。测试参数 `clear_review_enabled=False` 只关闭清空前复核；完整测试窗口默认开启复核。存疑标签及本次轨迹未用于训练个人模板。

## 验证结果

- 原168笔采集回放：第57、83、110、137笔由清空改为笔画；140笔笔画全部进入笔画流程，20笔真正清空仍判为清空，8笔两段往返仍不清空。
- 另回放 `data/stroke-test/20261012_204840_471532.jsonl`：原54条清空决策中，23条存在明显下降结构且得到折类模型支持，现保留为笔画。这份自由试写日志没有目标标签，因此23条不能直接计为已纠正误判或准确率。
- 相关131项自动检查通过，包括保存轨迹回归、缩放／平移／暂停／轻微倾斜、倾斜清空、模型异常、复核结果复用以及模糊识别、候选排序、七向选择、标点、删除和旧记录续采。

这些是开发回放与合成检查，尚不能保证所有新写法均被保护。下降太浅或下降主要发生在中间区间之外仍可能误清空；明显斜向下降的真实往返也可能被保守地保留为笔画。需要继续试写，并用带明确动作标签的独立会话验证。
