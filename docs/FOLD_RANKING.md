# 折笔细分与宽松排序

模糊笔画候选现已使用具体折笔类型。主程序与独立完整笔画测试共用
`StrokeDictionary.fuzzy_candidates`，重启后生效；关闭模糊匹配时仍按五类码查找。

## 数据

`assets/stroke-folds.json.gz` 保存 cnchar-order 3.2.6 的6934个逐字笔顺。
每个规范五类笔序都已确认存在于当前字典。原始细分字母保留，包含18组折笔。
cnchar 共享编码的横撇／横钩、斜钩／卧钩等作为集合处理，不强行细分。
录制模板另有“横折弯钩”和“竖折”两个名称，分别映射到 cnchar 的横斜钩组和竖弯组。
来源、版本、归档哈希、MIT许可证位置均保存在资产内。

数据依据：https://github.com/theajack/cnchar#54-笔画序列推出原汉字-ordertoword

只在候选笔顺与规范笔顺前缀一致的位置应用标签。其他版本、未覆盖字及缺少该笔形模板的
位置使用中性分数，不凭笔画数相同推断对齐关系。

## 排序与纠错

1. 五类码仍负责召回；具体折笔只参与截断前的全候选排序，不删除其他折类。
2. 使用自动识别保留的所有有效 `shape_scores`，不只取第一名或前两名。
   手动输入、只有类别标签、整体折类距离大于0.08的低质量轨迹不启用细分排序。
3. 每种笔形代价为与最佳折型的距离差，除以 `(0.06 + 最佳距离) × 模糊系数`，
   上限2.4。模糊系数随现有强度从0.5增至1.5，短／快笔画沿用已有自适应强度。
   强度越高，各折型间代价越平缓；所有折型始终可用。
4. 候选使用所属折型集合中代价最低的一种。接近的笔形获得加分，较远的笔形有有限惩罚；
   累计调整限制在±4分。词频、上下文和后续笔画可使非首选折型胜出。
5. 具体折型与原观察不同，记录 `fold_corrections` 和逐笔 `fold_matches`，
   保留原观察、五类码和轨迹，不消耗原有跨类别纠错次数。
6. 完整短字只有在折型兼容时才保留“已经写完”的绝对优先级。
   例如首笔明显是撇点时，乙仍在候选池内，但不会凭完整`z`码固定占据首位。

`fold_score` 是独立于跨类别纠错 `cost` 的排序项，不是概率。主程序的前五候选日志
记录细分分数、折型解释和内部纠错位置；排序参数位于日志的 `context_ranking.foldRanking`。

## 验证

新增测试覆盖：候选截断前重排、宽松折类内部纠错、上下文消歧、后续笔画消歧、共享编码、
名称映射、短字优先级、笔顺版本安全回退、手动输入、无效分数、模糊强度、资产对齐、
真实字典以及录制模板经DTW识别后的候选路径。

折笔、五类模糊、左点、强度、上下文、替换纠错、自适应、个人模型、DTW与结构识别
合计151项测试通过。扩大到所有名称含 stroke/joined 的测试时，517项通过，
3项失败、71项环境报错、2项跳过：环境报错涉及固定`/private/tmp`路径和Windows原生
Qt样式不支持自定义。3项失败涉及模拟设备启动和外部输入法提交；进程内禁用全部新增折笔
标注后，同样3项失败仍可复现，未将其算作本次通过的验证。
将`QT_QUICK_CONTROLS_STYLE`设为`Fusion`后重跑模糊界面、会话、个人学习界面、
候选批次、集成及完整测试窗口：137项通过，仅剩上述同样3项失败，无样式报错。

历史记录回放使用25轮已完成且无手动笔画的书写。共有1007个1–3笔状态，
其中264个状态含可用折笔细分证据。两组都使用6500常用字范围、当前上下文规则和
记录中的识别分数，只切换折笔细分；此对照未混入整字纠错或大模型选择。

|指标|原五类排序|加入折笔细分|
|---|---:|---:|
|首选命中|4.2%|12.5%|
|前3命中|15.2%|27.3%|
|前6命中|28.4%|37.9%|

142个状态排名改善，15个下降，其余不变。下降包括部分“向、时、雨、色”等，表明
轨迹子类型误差仍可能把目标字后移。回放不能证明新的硬件书写准确率或人的输入速度提升，
完成记录的筛选也可能低估困难情形。逐状态结果位于
`data/diagnostics/fold-ranking/replay.json`。

## 复现

```powershell
.runtime/venv/Scripts/python.exe tools/build_fold_annotations.py tmp/left-dot-research/cnchar-order.tgz
.runtime/venv/Scripts/python.exe -m pytest tests/test_stroke_folds.py tests/test_stroke_fuzzy.py tests/test_stroke_left_dots.py tests/test_stroke_fuzzy_strength.py tests/test_stroke_context_ranking.py tests/test_stroke_replacement.py
.runtime/venv/Scripts/python.exe tools/replay_fold_ranking.py
```

构建只读取本地固定版本归档和字典，不执行下载的JavaScript；应用运行时不联网取码表。
