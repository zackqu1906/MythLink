# MythLink UI 改造基线

更新：2026-09-29。依据用户提供的 Figma 截图及本任务中确认的方案。

## 范围与约束

- 沿用 Python、PySide6、Qt Quick / QML。
- 主导航固定为：首页、语音输入、场景与手势。
- 语音历史属于语音输入；首页仅提供最近记录与跳转入口。
- 戒指的蓝牙连接、重连、更换和断开入口统一放在首页；语音页只控制语音识别启停。未连接时只提供返回首页，不在语音页启动蓝牙操作。
- 保持语音、手势、设备、输入法、系统操作的业务逻辑与状态机。
- 用户后续授权的应用手势跨模式修复见第十二阶段：仅放行显式保存的应用菜单绑定，不改变语音专用及系统手势的用途。
- 用户后续要求扩大应用快捷键覆盖，见第十三阶段：修复菜单解析漏项，提供自定义单组快捷键，并沿用原有前台路由与锁定规则。
- 用户后续授权应用场景覆盖，见第十四阶段：首版支持 Microsoft PowerPoint 放映，允许在该场景复用全局占用的手势。
- 第十五阶段将放映扩展为演示类应用的通用场景，添加 WPS、Keynote 等应用时自动提供，已有应用启动后也自动识别。
- UI 使用现有 controller 属性与操作；页面切换和初始化不得重置配置或触发语音操作。
- 全局页继续只读；场景覆盖限定在明确添加的应用内，不增加全局重绑定机制。
- UI 的品牌名可使用 MythLink，应用设置标识、数据目录、打包和原生组件身份沿用现有值。
- 所有可编辑文本框统一使用框内浅灰色占位提示：获得焦点立即隐藏，失去焦点且内容为空时恢复；不使用浮动标签，也不将提示文字填入实际内容。单行、多行和快捷键录入分别复用 `UiTextField`、`UiTextArea` 及其派生组件，保留原有输入与保存行为。

## 场景与手势

目标交互为选择手势，再绑定动作。图标完整展示 11 个手势：顺时针旋转、握拳、逆时针旋转、上滑、左滑、Tap、右滑、下滑、食指捏合、食中捏合、响指。

全局与应用常规配置中，语音及系统手势以灰色卡呈现，可查看用途。演示类应用的「放映」配置开放场景覆盖，只有食指捏合（提示）和食中捏合（模式）始终保留。默认语音交互保持用户当前结构：文本框内 Tap 开始／结束，右滑处理编辑指令，左滑沿用撤销／取消；UI 读取实际绑定，不写入截图的示例动作。

应用列表默认空白，需要用户主动添加本机已安装的应用。选择应用后，通过 macOS 辅助功能读取其菜单公开的快捷键，供手势选择和保存；不能把设计稿示例或内置应用名单当作真实配置。菜单未公开的快捷键可自定义；PowerPoint 增加标准放映动作建议，仍由用户选择手势并保存后才生效。

## 设置归属

| 内容 | 归属 |
| --- | --- |
| 音频来源、麦克风、启停方式、有效的灵敏度参数 | 设置：麦克风与语音 |
| 撤销偏好、直接控制语音的键盘快捷键 | 设置：输入与控制 |
| 输入法、辅助功能、窗口预览授权 | 设置：系统与权限 |
| 菜单栏信息、离开锁屏 | 设置：通用选项与独立详情 |
| 应用动作、手势触发的快捷键、微信设置指南 | 场景与手势 |
| 模型、服务密钥、下载及性能配置 | 设置：高级设置独立窗口，统一滚动表单 |
| 实时日志和诊断 | 帮助：故障排查 |

只有一种选项的 ADPCM 编码不再提供下拉框；声音触发灵敏度只在靠近说话模式显示。隐藏选项不改变持久化值。模型和服务配置保留可发现的入口，避免无法修复服务配置。

当前高级设置导航以第十一阶段为准：设置页直接点击“高级设置”，在一个独立窗口内查看全部服务与性能配置，不再先展开入口、分别进入服务页，窗口内也不再折叠二级高级选项。

## 阶段进度

### 第一阶段：框架版（已完成）

- 浅色主题、三项导航、响应式页面容器、公共按钮与矢量图标。
- 首页：设备连接入口、真实连接／电量状态、统计空状态、快速开始、最近语音记录。
- 语音页：复用原有语音控件、历史列表及操作，只调整容器与配色。
- 手势页：完整卡片布局、三种锁定手势、全局／应用查看、实际映射详情、原应用快捷键编辑入口。
- 设置：保留原有可用详情面板，精简首页入口，服务配置折叠到更多配置，日志移到帮助。
- 不改业务 Python 源码、实时 HUD、输入法、系统辅助组件或设置格式。

### 第二阶段：首页设备管理与语音页（已完成）

- 首页明确显示蓝牙连接／重连／连接中／搜索中／断开状态；连接失败显示实际状态信息，更换设备继续遵循先断开的现有约束。
- 语音页移除连接、断开和更换设备按钮；未连接时返回首页，已连接时仅调用原有语音识别启停方法。
- 将语音页提取为 `VoicePage.qml`；状态、输入法提示、权限入口、旧模式选择、语音历史继续使用现有接口。
- 首页最近记录与语音页复用 `VoiceHistoryEntry.qml`：区分听写与编辑，展示结果、撤回／失败／取消状态；技术信息按需展开。
- 新增记录文本复制；成功且未撤回的记录复制结果，其余复制原文；成功清空文本时不把编辑指令误当成结果复制。
- 播放录音和打开记录文件夹移入每条记录的更多菜单；清空全部记录前增加确认，继续调用原清理方法。
- 设备通信、语音／手势状态机、历史存储与实时输入处理代码均不修改。

### 第三阶段：原始品牌与图标素材（已完成）

- 从 Figma 原稿取得完整 MythLink 商标、底部图标、导航及首页图标、11 个手势插画、戒指产品图。
- 替换框架版的示意图，按原始比例显示；不重绘商标，不使用通用字体拼接字标。
- 手势卡显示原版插画；Tap、左滑、右滑保留灰色锁定与查看用途的行为。
- 历史复制与更多操作改用原版图标；蓝牙入口、语音交互及映射逻辑不变。
- 素材随应用本地打包，详情见 `src/proximic_ring/ui/assets/figma/README.md`。

### 第四阶段：按应用读取菜单与编辑映射（已完成）

用户补充授权：应用默认空白、手动添加、读取辅助功能公开的菜单快捷键、只在目标应用前台生效，并使用最新的前台记录。

- 顶部栏目只保留“全局默认”、已添加应用的原生图标和唯一的“添加应用”入口；移除个别应用按钮、下拉框及右侧的添加／选择入口。图标按添加顺序排列，蓝色底和圆点表示当前选中，悬停显示应用名称。应用较多时横向滚动，添加按钮固定可见。
- “添加应用”直接打开搜索窗口并聚焦搜索框，默认展示当前打开的应用；输入名称搜索本机已安装应用，另提供“所有应用”与刷新。支持添加尚未启动的应用；读取菜单快捷键时若应用未运行，提示打开后刷新。
- 搜索合并标准应用目录（含系统和用户应用目录）、系统 Spotlight 应用索引及实时运行列表；按 bundle ID 去重，过滤内嵌辅助程序，索引异常时保留能扫描到的应用并提示。
- 图标由 macOS 从应用本身读取，异步加载并缓存，保存应用路径以支持重启后显示；不使用字母图标代替可读取的原图，也不自动启动或切换目标应用。
- 右侧编辑器直接搜索和选择菜单动作，显示完整菜单路径提示及实际按键组合；支持保存、取消与清除绑定。切换手势或应用保留本地草稿，不自动保存。
- 菜单仅读取 `AXMenuBar` 下的菜单元数据，不遍历窗口或读取输入框文本。读取有时间、节点及响应大小上限；部分结果和权限问题如实显示。当前禁用的菜单仍允许配置，并标注当前不可用。
- 应用及映射按 bundle ID 持久化到独立设置项 `gestures/applicationMenusV1`。新安装没有任何默认应用动作。已有显式保存的旧版配置保留，避免 UI 更新删除用户数据；某应用被手动添加到新编辑器后，以该应用的新配置为准。
- 菜单异步读取使用独立的原生通道；切换应用或刷新后，丢弃过期返回结果，不能串用另一应用的菜单。
- 手势识别时实时读取前台应用；执行前再次读取最新前台应用并核对 bundle、PID 和窗口。切换应用、重启进程、窗口变化、超过有效期或映射变化后取消旧操作，不排队补发。
- 新的菜单绑定继续使用现有输入模式和语音忙碌保护；不改变语音状态机、Ring 操作模式、上滑发送、系统手势和文本框内的语音交互。
- 完整保留 11 张原始手势图，搜索及保存图标也使用 Figma 原版素材。窄窗口采用同一滚动区域上下排列。
- 验证覆盖默认空状态、显式添加、持久化、真实目录校验、草稿、锁定、异步旧回复、前台切换、PID／窗口变化和语音忙碌；真实菜单和已安装应用读取只做只读检查，不向用户应用发送测试按键。新增验证包括未启动应用搜索、应用去重、图标切换、搜索框自动聚焦及窄窗口图标滚动。

### 第五阶段：设置分组表单（已完成）

- 依据 Figma 设置页 `274:1181` 将常用设置直接呈现在同一滚动表单，分为“麦克风与语音”“输入与控制”“系统与权限”“通用”，不再先选音频／输入分类。
- 新增可复用的表单分组、左右设置行、下拉框和开关；沿用现有主题。设置窗口自适应高度，“完成”固定在底部。原来音频与输入详情页的内部路由兼容跳转到新表单。
- 所有控件继续调用原有属性和方法。设备已连接或连接中时，音频来源、麦克风与语音启停方式仍不可修改；声音灵敏度只在靠近说话模式出现；切换模式只隐藏不适用的设置，不重置其值。
- 撤销偏好、转换按键和光标输入集中到“输入与控制”；旧模式的自动判断／文本整理和 Windows 按住说话只在对应模式／平台展示。手势重绑定不出现在常用设置中。
- 输入法与辅助功能使用真实状态及已有管理入口。窗口预览保留现有授权、刷新、验证、取消流程；打开设置不自动启动预览采集。权限不用应用内开关模拟。
- 菜单栏信息和离开锁屏入口位于“通用”；语音识别与文本处理服务仍折叠到“更多配置”。离开锁屏、服务密钥、输入法及授权详情保持现有功能。
- 从 Figma 取得三个分组原始 SVG，随应用本地打包。未实现的连接模式和音量测试不展示为可用功能。
- 本阶段仅修改 QML、原版图标、文档与验证，不修改语音、手势和设备 Python 逻辑。验证覆盖两个窗口尺寸、设置导航不改写配置／语音状态、单项修改只更新对应偏好，以及原有语音、授权预览取消等交互。

### 第六阶段：离开锁屏详情（已完成）

- 复用设置表单、主题、按钮和开关。顶部集中显示开关、实际戒指名称、状态及错误；常用区按校准戒指、解锁密码、系统权限排序。
- 校准显示实时进度与取消入口，完成／取消结果直接显示；密码设置、更新、访问授权、删除与权限操作继续调用原有方法，不新增密码输入或存储方式。
- 原有启用条件不变；若控制器拒绝开启，开关恢复真实状态。校准期间保留原有禁用规则，取消后仍由控制器恢复原监测状态和校准数据。
- 信号、基线、样本数量、远离确认次数、断连等待、组件位置和详细工作说明收进默认折叠的高级选项。开启监测期间参数仍不可修改，折叠不会重置值。
- 系统锁屏提示作为可选项保留复制与系统设置入口；沿用静态提示说明。连接戒指仍在首页，语音和手势执行代码不改。
- 隔离验证使用模拟原生进程，覆盖大小窗口、首次未配置、条件不足、校准进度／取消及监测恢复、原有密码／授权操作入口。没有连接真实戒指、读取密码或实际锁屏。

### 第七阶段：语音历史管理（已完成）

- 语音输入页增加文字／应用搜索、听写／编辑类型筛选、完成／撤回／失败／取消状态筛选，以及一键重置。条件可以组合，无匹配时显示对应空状态；搜索覆盖全部已保存记录，不限于最近 100 条。
- 长记录默认折叠，支持展开／收起；复制始终使用完整文本，保留原有成功结果／原文选择规则。原有录音播放、查看详情和文件位置入口继续可用。
- 每条记录的更多菜单增加删除，确认窗展示选定记录的时间与文字。确认绑定稳定记录 ID，即使此时新记录插入或筛选改变，也不会删除相邻记录；取消不改变数据，失败保留确认窗供重试。
- 单条删除适配现有历史存储：删除该记录及其录音，清理引用它的数据关联；其他记录、音频及无关关联保留。元数据写入失败时恢复，文件清理失败可重试；延迟到达的保存回调不会重新创建已删记录。
- 仅在删除当前回放的记录时停止该录音；保留正在进行的语音交互、已输入文字和撤销上下文。首页最近记录自动同步，但不在首页增加筛选与删除操作。
- 本阶段新增历史展示筛选与存储管理适配，不修改语音识别、手势执行和输入状态机。隔离验证覆盖大小窗口、组合筛选、实时更新、长文本、确认／取消／失败重试、并发音频保存、迟到回调及记录关联清理；没有删除用户真实记录。

### 第八阶段：应用配置管理与菜单状态（已完成）

- 选择应用后，在手势映射区显示应用名称、已绑定手势数量、菜单最近读取时间，以及刷新快捷键和管理应用入口。全局页不展示应用管理操作，添加应用仍只在顶部栏目。
- 管理菜单提供“清空此应用的映射”和“移除应用”。确认窗列明应用、已保存映射及未保存修改的数量，按应用标识锁定操作对象；取消不改变数据。清空保留应用图标；移除仅移除 MythLink 配置，不卸载应用。
- 两种操作只清除目标应用的绑定与草稿，保留其他应用的配置和草稿。移除当前应用后返回全局；重新添加从空配置开始，并排在图标列表末尾。异步返回的旧菜单不得重新填入已移除／重新添加的应用。
- 在现有配置中保留隐藏的移除标记，避免移除新版映射后自动启用旧版应用快捷键；标记随配置保存，重启后仍有效。继续调用原有配置变更通知和待执行操作取消方法，不改手势执行、前台目标校验或语音交互状态机。
- 已保存映射显示最近读取时的可用、不可用或未确认状态，区别菜单未读全、完整列表中未找到以及读取失败。缺少菜单启用状态时明确标为未确认；所有这些状态只用于展示，不自动清除／替换已保存绑定，也不保证菜单实时可用。
- 保留 Tap、左滑、右滑灰色锁定及原版手势图；新增操作沿用统一按钮与弹窗样式。大小窗口验证确认窗和保存按钮可见；隔离验证覆盖保存／取消、单应用清理、跨应用草稿、重新添加、旧回复、重启及旧版映射兼容，不对用户应用发送真实快捷键。

### 第九阶段：首页真实统计（已完成）

用户确认：时间指标使用真实录音的“语音使用时长”，不估算节省时间。

- 三张统计卡展示输入字数、语音使用时长和完成语音操作；默认今日，可切换全部记录。今日与昨日全天比较绝对差值，昨日无记录时明确提示，不计算没有基数的增长率。
- 输入字数仅计成功且未撤回的听写结果，按非空白字符统计，包含标点和字母；不把识别原文当作实际输入结果，也不重复计入编辑后的整段文档。完成次数仅计成功听写／编辑，每条记录计一次；失败、取消、撤回及已发送原生撤销的记录不计次数，应用快捷键不纳入本期统计。
- 时长汇总历史中保存的录音时长，包含未完成或已取消记录；按大小显示秒、分钟或小时。较大字数简写，悬停可查看完整数字。缺少结果或时长时明确提示，全部缺失时显示空值，保留合法零值。

- 验证使用模拟系统回调与临时设置，覆盖首次启动、已授权／已拒绝、原生请求未完成、设置返回、窗口焦点恢复、中途重启、异常及退出后的迟到回调。57 项权限与控制通道测试、66 项界面与语音交互回归通过。界面检查无自制授权弹窗，且语音状态与手势配置不变。未重置本机 TCC；完整的首次系统弹窗外观、App 名称和不同 macOS 版本行为需在未授权的打包 App 上验证。
- 接口依据：[Qt 应用权限](https://doc.qt.io/qt-6/permissions.html)、[Apple 辅助功能提示接口](https://developer.apple.com/documentation/applicationservices/1459186-axisprocesstrustedwithoptions)、[Apple 屏幕录制请求接口](https://developer.apple.com/documentation/coregraphics/cgrequestscreencaptureaccess%28%29)。

### 第二十四阶段：修复安装版首次授权被旧记录跳过（2026-09-30）

- 复现依据：安装版归档已包含第二十三阶段代码，但同一用户的 QSettings 中 `nativePermissionsV2Attempted` 已包含全部权限，安装版日志同时报告辅助功能和事件投递权限为未授权。旧记录由源码版与安装版共享，且把“检测时已授权”也记录为永久跳过。
- 改为每次启动读取当前系统状态；已授权仅跳过本轮，不写入请求记录。蓝牙／麦克风的系统状态始终优先于历史标记，未决定时仍可申请；请求异常或未真正调用系统接口不记录为完成。
- 新版请求记录按源码环境、应用路径和签名要求分开。Developer ID 正常更新使用稳定签名要求；本地 ad-hoc 重签使用对应代码哈希，避免旧构建的权限记录阻止新构建申请。旧 V2 记录保留但不再作为授权依据，不修改 macOS TCC，也不影响现有语音或手势设置。
- 增加内部 `PERMISSION_SETUP` 日志，说明每一步为什么跳过、请求或失败。安装包新增只读 `--permission-status` 检查及打包时权限后端检测；该检查不申请权限、不显示窗口、不写入设置。Qt 6.11 的本机权限插件已验证能加载，不以是否存在单独的 `plugins/permissions` 目录判断缺失。
- 补充旧记录迁移、源码／安装版隔离、ad-hoc 更新、过去已授权但当前缺失、未决定状态优先、失败不写入完成记录以及诊断只读性回归。
- 验证：80 项相关测试通过；新打包 App 的隔离启动探针正常退出，原生权限后端无加载错误，应用深度签名检查及 DMG 校验通过。产物为 `dist/ProximicVoice-0.6.0-macos-arm64-permissions-fix.dmg`。命令行只读探针的权限归属可能与 Finder 启动不同，因此不将其作为安装版实际获授权的证明；未重置本机权限，完整首次弹窗仍需在未授权环境验证。
