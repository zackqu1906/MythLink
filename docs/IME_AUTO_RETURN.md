# 语音输入后切回原输入法（实验）

设置位置：**设置 → 输入与控制 → 语音输入后切回原输入法**。默认关闭；关闭时沿用原来的输入法切换、润色和撤销流程。

开启后，语音起句借用 Mythlink 前记录原输入源。最终识别、编辑或已请求的润色写入输入框并确认后，保存本句的原生会话状态，再切回原输入法。停止收音本身不会触发切回。原本就选中 Mythlink 的会话保持 Mythlink。

切回后，润色和撤销手势会重新激活 Mythlink，核对原输入框、文本和光标，再恢复本句操作。操作完成后再次切回；润色后的首次撤销可以还原听写，下一次撤销删除本句。原有多次撤销开关仍控制较早句子的历史。发送或开始新一句后，不再恢复旧句。

输入框、文本或光标变化时不恢复旧句，也不退回应用的通用撤销。用户切换应用或输入源时，自动返回不会覆盖新的选择。无法核验输入框身份或文字的应用会保留 Mythlink，不强行切回。状态只保存在本次进程连接的内存中，退出或重新连接即丢弃。

## 试用

需要此分支的主程序、输入法组件和 `InputMethodAdmin` 一起更新；旧组件不支持会话挂起与恢复。

1. 运行 `scripts/build-input-method.sh` 构建组件，启动此分支的主程序，在设置中更新输入法。
2. 开启上述开关，在目标文本框中选中系统拼音或 ABC，再用语音手势输入一句话。
3. 确认最终文字写入后恢复原输入法；触发润色、还原听写和撤销，检查每次操作后都恢复原输入法。
4. 在切回后手动编辑文字或移动光标，再触发润色/撤销，确认旧句操作被拒绝。
5. 检查录音中请求润色、连续起句、取消、发送、切应用及关闭此设置。也需检查 Agent 输入框和推荐参数输入框的现有手势。
