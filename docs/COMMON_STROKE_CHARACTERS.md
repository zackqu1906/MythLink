# 常用字候选测试版

完整测试程序现在默认勾选“常用／通用字（6500）”，直接重新打开 `scripts/test-complete-stroke-input.cmd` 即可使用。取消勾选会恢复原全字库，当前笔序与正文保留，候选页回到第一页。范围切换会写入日志。

范围从原来的一级字表3500字扩大到《通用规范汉字表（2013）》一、二级字表共6500字，不是按当前语料出现次数截取。“霓”（字表6078号）和“袅”（4608号）原先被过滤，现已进入默认范围；6500字全部有本项目的笔画编码。Conway的旧常用字排名只覆盖部分字，因此不把“无排名”当作罕见字删除。

| 输入笔序 | 原全字库示例 | 常用字版本示例 |
|---|---|---|
| 竖 `s` | 丨、亅、是、以、中 | 是、以、中、上、些 |
| 撇竖 `ps` | 亻、的、你、但、他 | 的、你、但、他、仍 |
| 点点横 `nnh` | 氵、没、头、洗、油 | 没、头、洗、油、汤 |
| 点折 `nz` | 冖、帰、讠等 | 所、之、被、该、心 |
| 撇竖横竖 `pshs` | 什、仃等 | 什、仃均可输入，完整匹配优先 |

这些是严格匹配模式下的候选示例。默认模糊模式还会结合轨迹和上下文，但也受到同一范围限制。

白名单同时用于严格笔画候选、模糊候选、下一字联想、整字纠错和撇／删除语境辅助。筛选发生在排序、截断及分页之前，避免被排除字占掉候选名额。没有匹配时显示“无常用字匹配”，不自动补回白名单外字符。姓名、繁体字或其他字表外字符可取消勾选后输入。左点兼容标注也按6500字范围重新生成。

“霓、袅”已有完整逐笔字形。部分其他新增字超出现有字形资源或没有可验证的字形笔序，沿用普通字体显示，不显示不可靠的逐笔着色；仍可正常作为候选输入。

常用字范围内仍保留“完整且无需模糊替代的笔序优先”，因此“什”等已完整写出的字继续优先。恢复全字库会恢复原排序行为。本版不删除原始字库或重训笔画模板；模糊识别、清空前复核和七向选字仍可一起测试。

## 数据与核对

内置 `src/proximic_ring/assets/stroke-common-characters.json` 从 Unicode 官方 Unihan 17.0.0 的 `kTGH` 属性提取：2013年字表索引1–6500。生成时检查完整8105字表索引连续、所选6500字不重复；6500字全部存在于本项目笔画库。资产版本为2，实验范围记录为 `common-6500`；历史报告中的 `common-3500` 保留原含义。运行时只读内置名单，不访问网络；名单及来源包含SHA-256校验值。许可证随项目保存在 `unicode-license.txt`。

来源：[Unicode 的 kTGH 定义](https://unicode.org/reports/tr38/tr38-40.html#kTGH)、[官方固定版本数据](https://www.unicode.org/Public/17.0.0/ucd/Unihan.zip)、[教育部对一级字表的说明](https://www.moe.gov.cn/jyb_xwfb/xw_fbh/moe_2069/s7135/s7562/s7569/201308/t20130827_156353.html)。转录对照：[公开一级字表](https://github.com/shengdoushi/common-standard-chinese-characters-table/blob/master/level-1.txt)；实际内置资产以Unicode官方数据为源。

可用已经下载的固定数据重建：

```powershell
.runtime\venv\Scripts\python.exe tools/build_common_stroke_characters.py tmp/Unihan-17.0.0.zip
```

测试覆盖筛选先于截断、罕见完整匹配及强上下文无法突破白名单、无候选时不回退、无排名常用字保留、联想筛选、全字库切换和标点提交。

扩展范围的检查包括6500字笔序覆盖，“霓、袅”的严格／模糊候选、联想、整字纠错，以及完整测试窗口的实际选字提交。实际输入效果可继续用同一程序试写对比。
