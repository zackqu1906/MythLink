# 个人笔画学习

主程序的「笔画试写」和独立「完整输入测试」均提供「学习个人写法」、个人代号、撤回学习与清空档案。默认启用，默认代号为「默认」。多人轮流测试时使用 P01、P02 等不同代号；同一代号复用已有档案，代号不代表自动识别用户身份。

独立测试可通过原有脚本启动：

```powershell
scripts\test-complete-stroke-input.cmd --writing-profile P01
scripts\test-complete-stroke-input.cmd --writing-profile P01 --no-personal-learning
```

关闭学习会同时停止收集和应用个人模板，识别恢复为既有 DTW 基线（包含项目原来随包提供的静态模板）。已有档案保留，再次开启即可继续使用。主程序不允许在笔画组合或待提交时切换档案／学习状态。独立实验开始后锁定代号与开关。

## 学习时机与标签

- 原始传感器轨迹进入识别后，额外保留其方向和比例，按路径长度归一化为 32 点；显示用的标准笔形不参与学习。
- 本地输入实际插入文字后，或 macOS 原生输入法返回匹配的成功提交回执后，才尝试学习。失败提交、只识别未选字、联想选字但未写笔画、手动按钮／键盘输入均不会单独生成训练样本。
- 检查选中字的所有可行字典笔顺。提前选字只监督已经写过的前缀；多个可行笔顺在某个位置类别不一致时，该位置跳过。
- 标签只到横／竖／撇／点捺／折五类，不从字典编码推断具体折钩形状。左点的特殊输入约定不作为一般点类样本。
- 标签仍必须符合通用识别器的物理距离门槛：通用最佳距离不超过 0.08，标签距离不超过 0.12，且距最佳不超过 0.08。个人模型改变后的得分不能替自己背书。
- 独立测试中带漏笔、多笔或换序等「整字纠错」标记的选字，整个提交跳过学习。本版不推断轨迹与笔顺之间的编辑对齐。未被标记的实际错写也可能产生错误标签，因此这些门槛不能保证标签完全正确。

## 如何影响识别

保留通用 DTW 模型，另建每个档案的个人模板库。每类最多 16 个活动模板，来自最近 64 次有效选字；一次选字每类最多贡献 4 个活动模板，防止重复笔画占满模板库。

至少两次独立选字支持某类后，该类才参与调整。权重为 `min(0.65, n/(n+8))`，其中 n 是活动模板涉及的不同选字次数。本笔与个人模板距离超过 0.08 时，该类不参与调整。调整采用通用与个人距离的加权值，且仅在它优于原通用距离时生效；没有个人样本的类别继续使用通用距离。

这些距离和权重是原型启发式参数，不是校准概率，也没有通过多用户真实戒指实验确认最优值。本版主要学习局部轨迹写法，尚未实现佩戴角度／坐标系的全局校准。

## 撤回、存储与实验

退笔、清空笔序会丢弃相应的未确认轨迹。本地正文在当前档案加载期间被删除或替换时，根据内存中的文字前缀撤回受影响的学习；在较早位置编辑时可能保守地撤回更多样本。重新开始一轮实验会清空正文并重建文字跟踪，不会把上一轮的有效训练全部撤回。

「撤回学习」移除最近一次仍有效的学习记录，不删除正文；「清空档案」移除当前代号的全部个人样本。加载其他档案或重启后，先前正文的自动追踪不再保留，仍可手动撤回最近一次学习。外部输入框的任意编辑没有完整回执，无法自动检测其删除操作；误选后应手动撤回学习。

主程序存储在当前系统用户的应用 QSettings 中，键为 `touchpad/writers/<代号哈希>`；独立测试存储在项目 `data/stroke-profiles/<代号哈希>.json`。两处档案分别维护。只保存样本和确认 ID，不在档案中保存正文；文字撤回关联只存在内存中。文件、日志和样本均不上传。损坏档案退回通用识别并显示提示，不自动覆盖；可显式清空后重建。

独立测试日志记录档案、开关、学习和撤回事件。每轮 JSON 报告新增 `personal_learning`、`writing_profile`、`personal_model_initial`、`personal_model_final`，快照包含有效确认次数、各类支持数、活动样本数和档案指纹。初始快照用于区分新用户冷启动与已有档案；报告不会把测试原文用作学习标签。

建议用不同代号分别运行通用基线与开启学习的条件，并保留时间顺序：先识别、评分，再确认选字并更新；观察后续样本的识别率、选字笔数、翻页与纠错次数。跨用户、跨日期、重新佩戴后的收益仍需真实设备验证。
