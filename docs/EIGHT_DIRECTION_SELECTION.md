# 八向选字手势：先采数据，再决定识别规则

双击 `scripts/collect-eight-direction-selection.cmd`。此窗口直接使用本项目的 Ring SDK，采集一条连续触桌轨迹，最后抬手；选字菜单始终可见，途中不识别、不切换菜单。

```
↖ 标点 A       ↑ 标点 B       ↗ 标点 C
← 候选 4       先上滑再选方向   候选 5 →
↙ 候选 2       ↓ 候选 1       ↘ 候选 3
```

标点 A/B/C 只是位置占位，具体符号以后决定。蓝色高亮是当前任务提示，不是识别结果。第二段方向相对第一段结束的位置；菜单位置不代表整条轨迹的起终点方向。候选也只是位置提示，本次不写入文字。

## 首轮怎么采

1. 先断开 ProximicVoice 或手机程序对戒指的连接。在纸上标出八方向，并在左方向两侧标 15°、30° 辅助线；桌面方向保持一致。
2. 填参与者编号与佩戴／基准说明，选择“探索采集”，默认 **1 轮 100 笔**。建立新记录，连接戒指，等待预热 200/200。
3. 按 **1 或 Enter** 开始提示动作；全程触桌，停顿也不抬手；最后抬手。
4. 如果实际完成了提示动作，按 **1** 保存并开始下一笔，或按 **空格** 只保存。动作做错才按 **2** 重采。不要因为屏幕轨迹歪了重采，也不要跟着显示纠正手势；这正是要测的误差。
5. 采完导出 JSON。可分次完成：自动备份以及未确认草稿都能通过“续采 JSON”恢复。长时间休息、松转、重新佩戴后，应建立新记录并说明变化，便于区分会话。

## 一轮 100 笔覆盖什么

| 分组 | 数量 | 要检验的问题 |
| --- | ---: | --- |
| 上滑＋八向，每向自然／短／长／中间停顿 | 32 | 八向，尤其左右斜向，是否可分；长度和停顿的影响 |
| 上—上额外轻停、明显停顿、前短后长、前长后短 | 4 | 同向第二段是否留下速度或时间证据 |
| 单次八向，自然与长幅 | 16 | 没有上滑前缀时是否误触发 |
| 单次上滑中的轻停、明显停顿、缓慢滑动 | 3 | 一次上滑也可能停顿，是否与上—上混淆 |
| 左侧 ±15°、±30°，有／无上滑前缀 | 8 | 左／左上／左下的边界和方向漂移；作为边界探测，不强制分配菜单真值 |
| 32 种普通笔形 | 32 | 是否把普通笔画误判为选字 |
| 左滑、左右往返及轻点 | 5 | 是否与删除、清空、点击冲突 |

自然、短、长指个人舒适幅度，**不规定像素或厘米阈值**。提示里的停顿秒数只是动作引导；实际停顿是否达到该时长要从逐帧数据测量。连续上—上不要求停顿，必须保留其真实表现。

**如果连续上—上与单次长上滑的坐标和速度相同，仅靠轨迹无法区分意图。** 停顿也可能出现在一次上滑中，因此需要负对照，不能“看到停顿就判选字”。采集用于检验是否需要规定一个可辨认的上—上动作，或调整这个方向的交互。

## 保存内容与分析

新数据独立保存于 `data/recordings/selection-eight/selection-eight-<会话ID>.json`，相邻 `.events.jsonl` 保存连接期间的 SDK 事件。保留原始位移、未归一化坐标、200Hz 帧时间、主机到达时间、接触边界、草稿、重采与中断；不以现有点击判断过滤样本。200Hz 是模型帧率，不等于蓝牙或界面的刷新频率。SDK 位移不是实测厘米，也不是原始 IMU。

缺帧、重置、溢出或不完整接触会取消本笔并记录原因，不能伪造停顿。八向数据与已有笔画／删除采集记录分开保存，不改写历史数据或任务标签。

采完可运行：

```powershell
.\.runtime\venv\Scripts\python.exe tools\analyze_eight_direction_selection.py "导出文件.json"
```

分析输出到 `data/diagnostics/selection-eight/`：Markdown 概览、每笔 JSON、每笔 CSV。包括：

- 原始路径长度、净位移、总时长、直线程度及逐点积分核验。
- 不使用任务标签找出的几何分段：前后段长度、方向、转角、两段弦长增益 `chordGain`。直线也会有提议分段，增益接近零时不能认定存在一个折。
- 内部 30/60/100ms 最低路径速度区间及相对本笔速度的比值；另外保留最低速 60ms 区间中点的分段，对比几何分段。快往返不算停顿；开始和结束的自然减速区排除在低速窗口之外。
- 按方向、变体展示分布。第二段测角，不用整个上滑＋回滑的净方向代替。

分析器只是观测工具，不是已训练的手势识别器。首轮先看长度、停顿、折角哪些有区分力，随后确定分段算法与规则。冻结规则后，重新佩戴、另建“独立验证”记录（默认三轮 300 笔），单独报告八向混淆矩阵、完整手势正确率、拒识率、普通笔画／其他操作误触发率。对上—上必须分开报告连续、不同停顿和不同长度表现。

一轮或三轮只提供可行性探索，不能证明稳定达到 99%；训练和独立验证不可混用。重采和草稿用于诊断，不能作为已确认标签参与准确率统计。
