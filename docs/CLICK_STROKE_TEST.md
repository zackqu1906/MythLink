# 持续点击测试

双击 `scripts/test-click-stroke.cmd` 启动新版窗口。

1. 先关闭旧测试窗口、断开主程序的戒指连接，再启动新版。
2. 点“连接并开始记录”，等窗口显示“正在持续记录”。
3. 自由尝试轻点、较重点击、慢点击、快速连续点击、双击等方式。没有次数要求，也不用逐条确认。
4. 想标记当前方式时，可选下拉框；也可写备注并点“保存备注”。这些都是可选的，不会改变点击意图。
5. 结束时点“停止记录并断开”，或关闭窗口。点“打开数据文件夹”查看记录，然后告诉 Codex 采集完成。

所有观测记录自动标注 `intended: click`，预热阶段和正式采集阶段用 `phase` 区分。
即使变成笔画、点击检测成功、没有任何识别结果或发生数据异常，都保留记录；没有点击输出时，也保存原始数据和整个采集时间段。
程序无法从没有输出的区段准确计数物理点击，所以界面事件计数不是点击总数或准确率。

文件保存到 `data/tap-diagnostics/日期_时间.jsonl`。原始触控 token、增益前速度、接触概率、SDK 事件批次、点击判定与原因、固件手势、错误笔画及质量状态都会保存。
原始触控 token 是设备编码特征，不是原始 IMU 加速度。文件持续写入，每隔最多约 250 ms 刷新到文件，不需要等完成整套任务才能读取。
可随时停止或重新连接；同一窗口内继续保存在同一文件，重新打开创建新文件。
旧记录与模板不会覆盖或自动更新。本程序不控制系统鼠标，也不把文字输入外部应用。
