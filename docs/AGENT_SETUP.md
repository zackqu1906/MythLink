# Agent 在新 Mac 上的安装准备

当前 DMG 面向 Apple Silicon（M 系列）和 macOS 15+，不能当作 Intel Mac 或 Windows 安装包。

## 用户入口：设置 → Agent

此区域只保留三项：连接 Codex、语义召回模型、自动整理任务。连接成功显示绿色“已连接”，
模型完整且校验有效显示绿色“已下载”；两者沿用设置页的统一状态按钮。自动整理默认开启，
用户主动关闭后会记住选择。文本服务和系统权限继续使用各自的设置入口。

| 功能 | 所需准备 | 应用中的入口 |
|---|---|---|
| 基础 Agent、完整记录、持久化对话 | 用户自己的 Codex/ChatGPT 桌面应用、有效登录与可用额度 | 连接 Codex → 安装/连接/检查连接；连接异常时提供打开应用入口 |
| 操作桌面应用 | Codex 的 Computer Use 能力可用，按该应用提示完成系统权限 | 在 Codex 中配置 Computer Use；连接检查会提示不可用原因 |
| 截图、语音、笔画等输入 | Mythlink 的相关系统权限；语音服务配置；安装并启用输入法；使用戒指时连接设备 | 系统权限与输入法、麦克风与语音、语音识别服务 |
| 自动提取、后台同类复核和参数整理 | 用户自己的火山方舟 API Key、模型和服务地址；支持思考模式 | 文本处理服务；Agent → 自动整理任务开关（默认开启） |
| Workflow 语义召回 | 约 2.3 GB BGE-M3 模型、磁盘空间；编码运行时随包提供 | 语义召回模型 → 下载/继续下载；处理中可取消，完成后显示已下载并可校验 |
| 推荐 Hub | 已完成真实任务，提取并归并出可用操作 | 默认双食指捏合打开；新安装没有历史推荐是正常状态 |

本地文本编辑模型与 BGE-M3 是两个不同用途的模型；下载其中一个不会代替另一个。
当前 Workflow 在线思考适配只支持火山方舟。未配置时保留队列，不把配置缺失变成失败任务。
开启自动整理后，任务文字及工具记录会发送到用户配置的文本服务，消耗用户自己的额度。
下载召回模型仅请求公开模型文件，不发送任务、密钥或其他用户记录。

## 下载与恢复

- 权重保存到 `~/Library/Application Support/ProxiMic Voice/workflow-embedding/models/bge-m3/`。
- 逐文件校验固定 SHA-256 和大小，校验成功才生成安装标记。中断的 `.part` 文件不算安装完成。
- 取消或网络失败保留下载进度；下次按钮继续，服务不支持 Range 时重新下载该文件。
- 离线准备可把完整的固定版本模型文件夹复制到上述目录，再点“修复模型”校验；不能使用任意名称相同的其他版本。
- 更新 Mythlink 保留用户模型和记录；安装包不复制开发机的 API Key、Codex 登录或真实任务。
- 没有模型也能运行基础 Agent。归并等待模型，安装完成后继续。

## 发布与验证

`bash scripts/build-macos.sh` 构建 DMG。自检新增离线微型 XLM-R 前向计算和固定模型清单检查，
检查被冻结的后台入口和架构依赖，不依赖用户的模型缓存。正常使用时推理进程强制离线。
正式分发还需有效 Developer ID 签名和 Apple 公证；构建产生文件不等同于完成公证。

冷环境验收：新用户/临时数据目录打开应用，确认未配置状态清晰；完成模型下载或复制已有模型后校验；
连接该用户自己的 Codex；完成一条真实任务后检查记录、Codex 对话、Workflow、归并与 Hub。
模型测试只使用固定测试文字；Computer Use 是否开放、登录额度和系统授权仍由目标电脑实际检查。
